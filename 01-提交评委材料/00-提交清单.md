## 〇、官方提交与评选规则（照这四条交，别多交）

| 官方要求 | 我们的应对 |
|---|---|
| 提交**可运行/可播放的作品 + 作品名称 + 一句话介绍**，并勾选赛道；**同一作品提交一次** | 交线上链接（带 sharecode）+「据实·发布前事实核查」+ 一句话介绍（见下）；只报侦探赛道 |

> 官方两个字段的定义：**一句话介绍 = 用一句话介绍作品内容及用途**；**作品说明 = 介绍使用方式、亮点及实现思路**。下面两句按此定义写，逐字可直接复制。

**① 表单「一句话介绍」（108 字 · 内容 + 用途）**

> 「据实」是给中小商家、自媒体用的发布前事实核查工具：一句传言走「事实核查」判真假并给出处；要发的文案走「文案体检」按《广告法》查违禁词、逐句核不实宣称，给分数和改法。用在发布之前，避开罚款与翻车。查不到就明说查不到。

**② 表单「作品说明」**——两个版本二选一（内容一致、数字一致，只是组织方式不同）：

- `04-正式提交填表包/02-作品说明-表单版.md`（推荐）：正文严格三段 **一、使用方式 / 二、亮点 / 三、实现思路**，实证部分（真实提问与来源、评审维度对应、进阶项、已知边界）放文末标「附」；字数紧张时只贴正文。
- `04-正式提交填表包/作品详细说明.md`：七节连写版（标准 Markdown，可直接上传），进阶项与评审维度也在正文里，约 2,500 字。

**③ 作品说明文档（PDF/docx）里的一句话介绍（115 字，点名两个入口）**

> 「据实」是给中小商家、自媒体用的发布前事实核查工具：一句传言走「事实核查」判真假并给出处；要发的文案走「文案体检」按《广告法》查违禁词、逐句核不实宣称，给分数和改法。用在发布之前，避开罚款与翻车。查不到就明说查不到。

三处文案分工：①讲**内容 + 用途**（对应官方一句话介绍定义）；②讲**使用方式 + 亮点 + 实现思路**（对应官方作品说明定义）；③是作品说明文档的开场白，点名两个入口，避免评委误以为只有一个。

**时间线（官方）**：10/25 封板并按时提交 → 10/26–31 全国评审 → 11/1 全国颁奖直播。
**关键**：全国评审沿用 10/25 封板的作品，**不要求选手补交材料**——所以 10/25 16:00 前必须全部备齐，别指望"之后再补"。

**评审维度**：完成度与可用性 30% · 创意 25% · 场景价值 25% · 展示 20%（每项 0–10 分，加权后取评委平均分，同分合议）。
> 对应到材料：作品说明拿前三项，**2 分钟成片拿「展示 20%」**——这是为什么值得花一晚把片子做出来。

> **提交表单逐项怎么填**：见 `04-正式提交填表包/00-照着填-表单逐项.md`（一句话介绍 / 作品说明 / 封面 / 3 张截图 / 对话记录 MD / 可选字段 / 两个勾选项，全部可直接复制）。每个数字的验证出处见该包 `03-校验记录.md`。

## 五、评委可能追问的三句话（背下来）

1. **"这跟普通搜索有什么区别？"** → 搜索给十条链接，我给一个结论 + 为什么 + 出处；查不到就明说，不猜。
2. **"结论是模型编的吗？"** → 不是。模型只拆子主张、打立场标签，结论由规则引擎算，同输入同输出，有 6 例离线回归。
3. **"凭什么信你？"** → 每条结论都能点开来源；证据过十道闸；边界写在明处（不做个人私事、时政、推理审查）。
