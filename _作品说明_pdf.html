作品说明｜据实·发布前事实核查

赛道：1024超能 Coding周末·侦探｜查得到，信得过

作品名称：据实·发布前事实核查

一句话介绍：「据实」是给中小商家、自媒体用的发布前事实核查工具：一句传言走「事实核查」判真假并给出处；要发的文案走「文案体检」按《广告法》查违禁词、逐句核不实宣称，给分数和改法。用在发布之前，避开罚款与翻车。查不到就明说查不到。

口号：发布前，先查实。

体验方式：无需注册、无需账号，打开链接直接查询（可用真实问题直接验证）。

与赛道主题「查得到，信得过」的对应（三个词，三处可当场验证的地方）：

主题实现方式验证方式（约 30秒）
查得到真实检索：3轮、最多 9次，同一轮并发；先广搜、再攻矛盾、最后溯源一手材料查「隔夜菜致癌」→ 8次检索、引中国互联网联合辟谣平台，链接点得开
信得过·有据每条事实结论都绑定可点开来源；来源过十道闸（去重、转载合并、否定式守卫、主体校验）点开任意一条结论的「展开：它查了什么」，看到每轮查询与原文链接
信得过·不编证据不够就拒答：查不到明说「没查到可靠来源」，来源打架就说分歧，边界问题直接拦（0检索）查「我同事是不是老赖」→拒答·0检索；查「下月全国药店停售感冒药」→没查到

一条容易误解的地方先讲清：体检入口里的「违禁词按法条判定」只处理用词这一小层，凡是事实宣称仍然走同一条检索链（每句最多 3次检索、附来源）。所以它不是词库工具，检索核查才是主体。

进阶项做了没有证据

补一句为什么这样取舍：官方写的是"选做、做到明显加分"。我们选的是与赛道主题「查得到，信得过」最贴的两条——多轮检索与截图查证都直接服务"带着证据回来"；盯梢属于运营能力，做不好反而会给出过期提醒。

最大卖点：宁可说查不到，绝不编——查不到时它明说"没查到可靠来源"，来源打架时它讲清楚听了谁、为什么；凡是靠检索得出的结论，都带可点开的原始来源。在这条赛道，说不知道不扣分，瞎编才扣分。

七项差异化设计（同类开源查证工具与词库工具均未提供）：

1. 法条判定与检索核查是两条路——违禁词按法条明文给依据与改法（0检索）；事实宣称才去检索。市面上的词库工具只会命中文案词表，说不出"这句话错在哪、该改成什么"。

2. 广告语里的"谎"也能查——「日本引进」不在任何词库里，我们靠「处罚通报提权 +数字必须点中」把它判成假 70，并指向市场监管总局的典型案例。这是词库工具的盲区，也是本作品最硬的差异点。

3. 五档结论 +权威优先——真 /假 / 误导 /说不准 /没查到；不按来源条数投票，只看最高权威层级有没有定论；来源打架就明说是分歧，不硬凑答案。

4. 转载合并与同站去重——五家媒体转同一篇稿，只算 1条证据；同一家既支持又反驳，两边都作废。大部分工具会把"十家转载"当成"十方印证"。

5. 拒答是架构结果，不是态度——个人私事、时政在入口就被拦下，一次检索都不发生；查不到可靠来源就明说查不到，不拿模型记忆凑答案。

6. 服务类文案不误杀——能自证的（开了几年、人均多少）给"留存材料"提示，需要外部举证的（除醛率 99%）才去检索。这条是拿真实用户的文案调出来的：修之前，一段正常的个人服务文案会被判 D。

7. 企业信用只认政府与司法公示——媒体报道、商业数据库一律不采信，避免把"高管被处分"误读成"企业失信"（处罚 ≠失信，两件事在代码里是隔离的）。

核心结论（三句）：

第一，它卡在发布前，不是辟谣后。第二，每条结论都带得走——来源点得开、数据可对账。第三，查不到就说查不到，边界写在明处。

两个入口的职责划分（易混点说明）：

入口输入做什么检索消耗
文案体检一段待发布文案（≤1000字）①违禁词命中句 → 按法条规则判定，0次检索 ②其余句里的事实宣称 →取前 8句深查 ③其余标「未核查」最多 8句 × 3次 = 24次；违禁词句 0次
事实核查一句话（≤200字）只核这句话的真假：拆子主张 →三轮检索 →五档结论每次最多 9次；不扫违禁词

三个「0次检索」不是一回事，这里分清楚：

0检索的情形属于哪个入口为什么可以不查
违禁词命中（最、第一、零风险…）只有文案体检纯用词问题，法条有明文，不需要查证
受理边界拒答（个人私事、时政）两个入口都有不在受理范围，不查就是不查
常识短路（如「鸡蛋含有蛋白质」）只有事实核查教科书级常识，检索只会引入"沾边不相关"的噪音；结论标「通用知识·未检索」。机构、数字承诺、时效、健康因果四类一律不走常识、必须检索——所以「中国移动是国企」会照常检索 7次并引国资委来源

除此之外，事实核查的每条结论都必须有检索到的来源支撑——查不到就说"没查到可靠来源"，绝不凭模型印象下结论。

1.它解决什么问题

先说清楚它不是什么：它不是一个"辟谣助手"。

辟谣是 C端已经饱和的活（微信辟谣、腾讯较真、各平台官方号都在做）。这个作品的落点在发布之前——小店老板写海报、写团购页、写短视频口播时，先查一遍这句话站不站得住。

AI最容易被骂的不是不会，是说错说得太自信。

把它放到真实场景里，痛点是两个方向的：

谁他的问题现在的产品怎么答
普通家庭群「这条转发是真的吗」查证卡：真 /假 / 误导 /说不准 /没查到可靠来源
小店老板、中小企业主「我这段话发出去会不会被罚」风险清单：哪句有事、依据是什么、怎么改

第二个方向是入口。街边一张海报上写「最正宗」「零添加」「包治」，被举报一次罚 2–3.5万（已有行政处罚先例）。而市面上现成的工具都在查"有没有禁用词"，查不出「日本引进」这种不是词、是谎的宣称——郑州一家企业就因这类表述被罚 20万（市野（郑州）网络科技有限公司"市野医生筋骨疼痛贴"案，2025年 5月郑州市市场监管局处罚，系国家市场监管总局公布的十起违法广告典型案例之一）。

所以这个作品的能力锚点放在：能查事实、能亮出处、能承认不知道。

2.它怎么查（多步，不是搜一次就答）

固定 3轮，全过程在页面「展开：它查了什么」里可见：

轮目的查询怎么构造
R1广搜摸清基本盘关键词 Cnt=20, Mode=2 +一路 Industry=gov只看官方口径
R2深挖攻缺口与矛盾①反向查询（辟谣/反驳/数据不一致）②Site限定权威域 ③换词换口径 ④针对最薄弱的子主张单独补一路
R3溯源找一手材料Freshness拉早期 +定位原文、原始研究、官方通报、处罚决定书

约束：最多 3轮 / 9次检索（同一轮的查询并发发出，通常 6–10秒出结果）。不提前收手——即使第一轮看起来一致，也照常跑完二、三轮；有争议的说法必须拿到反方证据和一手材料。

每轮模型只输出一句结构化判断：{"need_more":…, "queries":[…], "missing":"缺 XX的原始数据"}——那句 missing会直接显示在卡片上。

体检模式（面向老板）先用规则定位、再按句分四路处理：

违禁词命中句 →法条规则判定（0检索，直接给依据和改法） → 服务类句子（说明服务、描述痛点、自我介绍、经营细节）→只给提示或不处理，不占用检索名额 → 其余句里的事实宣称 →取前 8句深查（每句最多 3次检索） → 清单汇总，未深查的标「未核查」。

词库只负责定位「哪句该看」，判定分三条路走：违禁词靠法条明文，效果保证靠法条禁止性规定，事实宣称才靠检索。

为什么要把服务类拆出来：小店老板写「我帮你把 AI落到业务里」「教你的员工学会用」，这是服务范围，公开渠道本就不会有第三方证据。早期版本把它当事实宣称去查，查不到就判高风险，结果正常文案一贴就是 D级——严格不等于误伤，这一层修正后，同一段服务文案判 A，而「祖传秘方/包治/销量第一」照样判 D。

3.它怎么判（结论由算法算，不由模型编）

这是和"套壳聊天机器人"的分界线：

1. 子主张拆分：一句话常混 2–4个子主张（隔夜菜 →亚硝酸盐是否升高 /是否超国标 /是否致癌），混在一起判必错。逐条判定后汇总成矩阵，一眼看出哪一环断链。

2. 四维判决：一手性（原始通报/论文/判决书 >二手转述 >自媒体互转）、权威度（authority_level或域名白名单）、时效、利益相关（商家自测、带货号降权）。来源打架时给对比表，并写清"采纳 A不采纳 B"的理由。

3. 拒答闸门（代码层，不靠提示词）：高质量证据 < 2条 → 说不准；只有低权威或利益相关来源 → 没查到可靠来源；只搜到相近新闻 → 相关 ≠支持；模型引用未给出的来源 →丢弃重试，仍失败则回退规则结论。

4. 举证责任倒置（宣传类）：广告主对内容真实性负责，拿不出依据就不建议这么写。所以宣传类查不到依据 =高风险，而不是"没事"。

LLM的权限被限制到最小：只做两件事——拆子主张、给单条证据打立场标签。结论永远由 judge.py算。同输入同输出，可复现、可回归测试。

4.检索为何是不可替代的环节

这个作品的判定链是 检索 →证据分级 →判决，三段都离不开实时搜索：

环节换成模型自身知识会怎样
断言判定模型只能凭训练记忆猜真假，而训练数据有截止日期，最新通报、最新处罚、最新抽检结果它都没有
来源可点开模型给不出可验证链接，给了也可能是编的（正是赛道题干里说的"幻觉"）
第三轮溯源找"这条说法最早出自哪、官方什么时候辟的谣"——只有检索能做，模型记忆里没有传播链

关掉检索，这个作品立刻退化成"会自信编答案的聊天机器人"。

反过来说，"敢说不知道"不是产品美德，是检索架构的必然结果：没有证据时它没有东西可以编。

9.对标与可复用性

9.1对标业内最佳实践（2026-10-23实测开源项目）

开发中逐条对照了 GitHub上三个最接近的同类项目——bullshit-detector（158★，逐主张核查 agent）、ClaimeAI（106★，LangGraph拆解主张）、FIRE（MBZUAI实验室，迭代检索查证框架）。对照结论：

业内最佳实践本作品
无来源不给结论，模型记忆不算数✅结论必须有真实证据支撑，引不出编号就退回拒答
主动搜「反驳角度」，不重复搜同类✅第二轮专门攻矛盾（refute检索）
重新检索前先「说出缺什么」✅缺口驱动的下一轮检索规划
没查到的主张明示而非隐藏✅折叠区「未核查」+报告「没查到不推测」
报告透明化（查了几次、多久、每轮查询词）✅三轮轨迹表 +「检索 N次 /耗时 X秒」
按文档评级，不按域名评级✅权威度之外还有 on_topic +强相关判断：同一个政府站的另一篇文章不算证据
转载合并到原始出处再计数✅同立场下标题重复的来源只留一条——五家转载同一篇稿子不是五条佐证
steelman：判重之前先找宽容解读✅误导档识别不出归因纠正信号时退回「假」，不硬扣更重的帽子

本作品多出来的（三个对标项目均无）：

中文广告法场景的违禁词法条判定（0检索给法条依据与逐句改法；仅「文案体检」入口，事实核查入口不含此能力）

中文语料的立场守卫：设问式标题（「喝咖啡会致癌?真相是这样的」）、否定式表述（「不會增加患癌風險」）、繁体中文、辟谣平台稿件——这四类会把开源工具的立场判断直接带反，本作品用规则闸门兜住（详见算法文档「十道闸」）

企业信用专项口径（只认政府司法公示，杜绝媒体报道误判）

误导（misleading）独立档——bullshit-detector同样有这一档，本作品与其结论一致；「咖啡致癌」这类张冠李戴说法，权威来源在纠正归因（"原报告针对的是65℃热饮"）时判误导，直接定性谣言时才判假，识别不出时保守退回「假」

权威优先裁决：不数来源条数，只看最高权威层级——FIRE用动态停止省成本，本作品曾经试过提前收手、因为有争议说法会漏掉交叉验证与溯源而主动删掉，宁可多花三次检索，不在证据链上偷工

判定链是通用的：抽取断言 →多路检索 →证据分级 →冲突判决 →敢拒答。

换掉"断言类型"和"证据偏好"，同一套引擎可以接别的活：

场景换掉什么谁需要

10.边界与诚实清单

参考业内同类开源项目（bullshit-detector的「What it doesn't do / Honest limits」）的写法：一个查证工具不靠"什么都能查"取信，靠把不会做的事、会错的地方、错了怎么办写清楚。下面三块都可以当场验证。

边界不是免责声明，而是把「信得过」落到实处——说清楚什么时候不给答案，剩下的答案才可信。

10.1明确不做（命中即拒答，0次检索）

不做为什么怎么验证
具体个人的私事：品行、信用、债务、健康、行踪查个人不是本工具的场景，且极易伤人输入「我同事张三是不是老赖」→拒答·0检索
时政话题：领导人、选举、军演、外国政坛超出事实核查范畴，也超出模型该下判断的范围输入「美国下一届总统是谁」→拒答·0检索
判真假之外的判断：合不合法、该不该罚、赔多少那是律师与执法的活报告与页面固定写"不构成法律意见"
个人资质的真假：证书、职称公开检索核不到，查不到不等于假只提示补证书名称与机构，不判真假
推理是否成立前提全真、结论也可能推不出来——这是论证问题，不是事实问题与对标项目同一个取舍：只查断言，不审逻辑

企业不受个人边界限制：查企业信用走政府与司法公示（失信名单本身），不涉及个人信息。医疗、统计类的公开标准也不拦（「高血压的诊断标准是 140/90」会正常检索）；只有带人物主语的个人病情、工资、住址才拦。

10.2已知局限（主动说明）

局限具体表现我们的处理
检索是不确定的同一句话隔几分钟再查，返回的证据集可能有差异（对标项目 10例实测：同一内容跑三次，一半断言至少变过一次结论）每张卡都标查询时间与检索次数，一次结果只当"一次读数"，不当"最终定论"
只能引到能访问的来源高权威站点反爬、付费墙、公众号不收录 →只能拿可得来源，SEO内容可能趁虚而入权威度分级 +利益相关降权 +同站去重 +转载合并；宁可判"没查到"，不拿营销号凑数
相关性判断偏严沾边但没谈这件事的文章不算证据；代价是"能用来源变少"，结果是更多"说不准/没查到"十道闸 +最后一关三查，这是"绝不编"的必要成本
数字类断言要盯数字讲同一主体的另一件事（如"高血压误区"）容易被当成反驳 140/90的证据反驳类证据的标题必须点到断言里的数字，否则降级（2026-10-23实测事故后新增）
双栏海报的半截话两栏排版被 OCR读成一行再切句，会出现「1适合这样的企业」「希望尽快见效」这类半截话；早先它们被当成事实宣称去检索，只能匹配到毫不相干的页面，进而被判成「与公开来源不符」已修（2026-10-24 10:53）：碎片句在深查前被识别并剔除——不检索、不计风险，也不计入「干净句」以免虚报。597字脱敏海报实测由 D·0变为 B·84（检索 3次、8秒）

10.4出错时的行为（比准确率更重要）

没检索就不给结论：未深查的句子标「未核查」，不猜

来源打架就说打架：给对比表并说明"采纳 A不采纳 B"的理由，不硬凑一个答案

改过就留痕：查证编号不连续，因为删过旧逻辑下的错误记录——这本身就是"结果可纠错"的证据

10.5其他已知限制

体检模式：违禁词句按法条明文判定（0检索），可核宣称句深查（每句最多 3次），其余进折叠区标「未核查」

服务类句子不做检索判定：服务说明（我帮你落地）、痛点描述（工具买了闲置）、经营自述（开了八年、人均 25元）都不进检索队列；经营自述给「留意留存材料」的低风险提示。效果保证（「保证学会」「无效退款」）按广告法禁止性规定判中风险，个人资质（「我是 XX训练师」）提示补证书信息——这两类都不判真假，因为依据不在搜索结果里

违禁词判定只在「文案体检」入口存在；「事实核查」入口只核事实真假，不判断是否违禁。两个入口不能互相替代

需要专业数据库（司法判例全文、商标库、专利全文）的断言，能力有限
