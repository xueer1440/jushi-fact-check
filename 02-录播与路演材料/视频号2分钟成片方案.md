## 0. 先说一件必须知道的事：微信里打不开（实测）

用微信内置浏览器的 UA 访问，托管平台会返回一个「**请在浏览器中打开**」的页面（HTTP 403）；换成手机 Safari / 电脑 Chrome 的 UA，正常 200。这是托管层对微信 UA 的限制，不是作品的问题，但**会影响所有引流话术**：

- 观众在微信里点链接 → 看到"请在浏览器中打开"，多数人会直接退出
- 微信扫一扫/长按识别二维码 → 还是走微信内置浏览器 → 同样被拦
- 所以**别再写"微信点开就能用""评论区有链接"**

**能走通的三条路（按转化率排）**：

| 顺序 | 做法 | 具体话术 |
|---|---|---|
| ① | 发链接时直接给操作指令 | 「复制链接 → 粘贴到手机浏览器打开（微信里会提示在浏览器中打开）」 |
| ② | 私信/群里发链接 + 一句提示 | 「链接发你了，**复制到浏览器**打开，微信里点会拦」 |
| ③ | 电脑端演示给评委看 | 评委多数用电脑浏览器，直接打开没问题；视频里也以电脑录屏为主更稳 |

> 二维码仍然可用，但只能帮人"拿到链接"，不能"直接在微信里打开"。**别在片尾只放二维码不写字**，要配一句"复制到浏览器打开"。

## 0.5 没有公众号怎么办

视频号**评论区、简介都不支持可点击外链**，这跟有没有公众号无关。公众号只是"扩展链接"的一种挂载方式，你没有，那就换三条腿走路：

| 方式 | 怎么做 | 转化率 | 备注 |
|---|---|---|---|
| **① 片尾二维码**（主推） | 最后 3 秒定格一张二维码图，配字幕"暂停截图 → 长按识别" | 中 | 微信原生支持长按识别图片里的二维码；务必用**带 sharecode 的链接**生成二维码 |
| **② 评论区置顶** | "入口：私信我发你" / "微信搜一搜：据实" | 中 | 私信可手动回，别指望自动回复（设置入口在各账号不一样，发布前自己试一次） |
| **③ 朋友圈/群转发** | 视频号发完，转发到朋友圈时配一句带链接的文字 | 高 | 朋友圈文字里的链接可点，这是你唯一能"直接点开"的地方 |

> **发布前必做一次实测**：自己在微信「搜一搜」里搜"据实 事实核查"，看能不能搜到。搜得到就把"微信搜一搜"写进简介；搜不到就只留二维码 + 私信。**别写不确定的引导语**，观众搜不到会直接划走。

**二维码怎么出**：用带 sharecode 的完整链接生成（草料二维码即可），存成 `assets/owner_qr.png` 那种规格，剪映里做一张 3 秒定格卡。

## 1. 四条要查的话（复制粘贴，一个字别改）

> 2 分钟能放 4 段，顺序别换：**先"谎言被罚"→ 再"谣言被打脸"→ 再"该拒就拒"→ 最后"对老板有用"**。情绪一路往上走。

### 第 1 条（郑州广告语 · 判假 · 约 12 秒）

```
「日本引进」「一盒让三年疼痛消失」
```

- 预期：**假 · 置信 70**，检索 8 次
- 必须点开：**「关键依据」第一条《国产筋骨贴冒充日本货?罚款20万!》**（搜狐网；标题里就有"罚款20万"）
- 这条是全片钩子的闭环——开头说"罚了 20 万"，这里证明"我真查到了那张罚单"

### 第 2 条（隔夜菜 · 判假 · 约 10 秒）

```
隔夜菜亚硝酸盐超标会致癌，千万别吃
```

- 预期：**假 · 置信 90**，检索 8 次
- 必须点开：**中国互联网联合辟谣平台**（权威度 5/5）

### 第 3 条（拒答 · 约 3 秒）

```
我同事张三是不是老赖，听说欠了很多钱
```

- 预期：**不在受理范围 · 0 次检索**
- 停住别切，让"0 次检索"露出来

### 第 4 条（文案体检 · 约 10 秒）

```
本店祖传秘方，纯天然零添加，包治颈椎病，一次见效，全网最低价，销量第一。
```

- 预期：**D · 不建议发布（2 分）· 0 次检索**（实测 0181：6 句 / 高风险 5 / 违禁词 7 / 结语「5 处违禁词」——7 是词条数、5 是句子数，两个数页面上都显示）
- 要拍到：红色 **D** 徽章、分数 **2**、任意一条的「建议」改法

> 四条合计约 19 次检索，单次录制 3–4 分钟可完成（等待段后期加速 2–4 倍）。

## 2. 口播稿（120 秒 · 去 AI 味版）

> `/` 是换气位，**加粗**是要加重。全稿约 470 字，按 4.4 字/秒 ≈ 107 秒，留 13 秒给停顿与画面。
> 口播里说「置信度」，不说「分」——观众会把「70 分」误听成打分。

```
【0-6s】AI 编瞎话的时候，最气人的不是它错。
        是它**特别自信**。

【6-16s】郑州有家企业，海报上写了四个字：日本引进。
        罚了二十万。

【16-26s】注意，这四个字不在任何违禁词库里。
        词库工具查不出来。
        因为它**不是用词问题，是句谎**。

【26-36s】所以我做了个东西，叫据实。
        你把要发的话丢进去，它替你去网上查。

【36-56s】（录屏①：郑州广告语 → 假 70 → 点开监管通报）
        先看这个。日本引进，一盒让三年疼痛消失。
        假的，置信度七十。
        四条来源指向同一件事：这类话被查处过。
        点开这条，标题里就写着「罚款20万」。

【56-74s】（录屏②：隔夜菜 → 假 90 → 点开辟谣平台）
        再看一个家家都转过的：隔夜菜致癌。
        假的，置信度九十。
        辟谣平台的原话在这，一句话就把这事说清了。

【74-88s】（录屏③：老赖 → 拒答）
        那查人呢？
        它**一次检索都不碰**。
        个人私事，不在我的范围。
        说不知道不扣分，瞎编才扣分。

【88-108s】（录屏④：文案体检 → D 级 + 逐句改法）
        开店的听我一句。
        海报发出去之前，先查一遍。
        祖传秘方、包治颈椎病、销量第一——**七处违禁词、五句踩线**，直接 **D 级**。
        每一句该改成什么，它写给你。

【108-118s】它凭什么敢下结论？
        每条结论都得有能点开的来源，
        证据还得过**十道筛子**。
        查不到，就明说查不到。

【118-120s】据实。发布前，先查实。
```

## 4. 录屏 SOP（4 条一次录完）

**准备**
- [ ] 打开带 sharecode 的链接：`https://jushi-fact-check.app.workbuddy.host/?sharecode=T3NGFV6FVO`
- [ ] 手机：微信打开 → 右上角「在浏览器打开」；开飞行模式再关（防来电横幅）；关通知
- [ ] 电脑：浏览器 F11 全屏 + 隐藏书签栏（Ctrl+Shift+B）+ 只留一个标签页
- [ ] 先自己跑一遍四条，确认结果都出得来（第 1、2 条各要等 6–10 秒）
- [ ] 录屏：手机用系统录屏（竖屏）；电脑用 OBS（1080p / 30fps / 8Mbps）

**录制要点**
1. **手慢**：每次点击前停 0.5 秒，观众才跟得上
2. **停留**：两条来源各停 1.5 秒，拒答页停 2 秒——这三处是全片信任感的来源
3. **一镜到底**：四条连着录，中间不暂停（后期只加速、不改顺序）
4. 录完立刻回看：来源链接是否真的点开、D 徽章是否清晰

## 5. 配音（两条路）

**A. 真人（推荐）**
- 手机录音即可，找小房间、衣柜前录，回声最小
- 麦距 15cm，别正对喷气；语速 **4.2–4.8 字/秒**
- 三种语气：钩子压低放慢 → 演示段平实 → 收尾提一点、收干净
- 每句录两遍挑最像"跟人说话"的

**B. 剪映 TTS**
- 文本朗读 → 「解说小哥 / 沉稳男声」，语速 **1.0–1.05**（别超 1.1，一快就露馅）
- 长句用逗号切开，停顿全靠标点
- 生成后变速微调到 107–112 秒
- 确认"据实"读音（jù shí），念错就换真人

## 6. 剪辑（剪映，15 分钟）

1. 新建 9:16 项目（1080×1920）
2. 按分镜顺序拼 4 段录屏
3. 等待段加速 2–4 倍（检索转圈别让观众等）

6. BGM 压到 -22dB；人声为主
7. 片尾加二维码定格卡（2.5–3 秒）
8. 导出 1080×1920 / 30fps / 8–12Mbps

**封面三选一**：「海报写这四个字，罚 20 万」「AI 编瞎话时，特别自信」「一句话，查三轮」

## 8. 如果路演现场讲（不播视频）

2 分钟现场版把"录屏"换成两个现场动作，其余口播不变：

| 时间 | 动作 |
|---|---|
| 0–26s | 只讲钩子，不碰电脑（罚 20 万 + 词库查不出） |
| 26–40s | 说"我现场查一条给你们看"，输入**隔夜菜**，等结果（6–10 秒，用嘴填："它现在在查三轮"） |
| 40–70s | 结果出「假 90」→ 点开来源 → 讲十道筛子（一句白话："五家转载同一篇，只算一条"） |
| 70–90s | 输入**老赖** → 拒答 → "0 次检索，这是硬保证" |
| 90–110s | 切体检，粘第 4 条 → D 2 分 → "七处违禁词、五句踩线，每句都给改法" |
| 110–120s | 收尾：发布前，先查实 |

> 现场版只查 2 条（隔夜菜 + 老赖），体检那屏提前截好图备用——现场网络不给力时不至于尴尬。
