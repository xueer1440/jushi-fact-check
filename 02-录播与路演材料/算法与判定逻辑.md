# 据实 · 算法与判定逻辑全解

> 版本：2026-10-23 21:55（同步：服务类文案四子型、时政与医疗词边界修正、十道闸口径、9 次检索预算、五档判定）
> 对应代码：`detective/`（claims / planner / judge / investigator / checkup / lexicon / rules）

---

## 0. 三条铁律

1. **词库只负责"定位哪句值得查"，绝不负责"判定它违法"。**
2. **没有可采信的依据，就不给"真/假"**，只给"没查到可靠来源"。
3. **任何结论都必须能被某条真实存在的来源支撑**——模型可以判，但要点名依据哪一条，引不出来就不算。

## 1. 两个入口，共用一个引擎

| 入口 | 输入 | 做什么 | 上限 |
|---|---|---|---|
| 文案体检 | 整段即将发布的文案 | 逐句扫违禁词 + 挑 8 句核事实宣称 → 打分 + 逐句改法 | 1000 字 |
| 事实核查 | 一条说法 | 拆子主张 → 三轮检索 → 判真/假/误导/说不准/查不到 | 200 字 |

体检内部对每一条"事实宣称"调用同一个 `investigate()`，所以两者的判定口径完全一致。

## 2. 第一层：这句话属于哪一类

`claims.classify_claim()` **按顺序**判，先命中先返回：

| 顺序 | 类型 | 触发条件 | 判法 |
|---|---|---|---|
| 1 | **实时信息** | 含"今天/明天/天气/油价/汇率/股价"等词，**且** ≤30 字，**且** 无第一人称，**且** 不含"取消/发布/政策/新规/通知"等政策词 | 不判真假，只列最新来源 |
| 2 | **个人资质自称** | "我是/本人/持有/持证" + 训练师/证书/认证/资质/讲师… | 规则提示补证书，**0 检索** |
| 3 | **效果保证** | 保证／确保／必能／包会／包过／无效退款／"学完就能"… | 规则判保证性承诺，**0 检索** |
| 4 | **宣传宣称** | "最X"、"第一"、广告法词（唯一/顶级/纯天然/根治…）、产地与功效广告语（引进/进口/原装/专利/止痛/疼痛消失…）、或第一人称+推广话术 | 举证责任倒置 |
| 5 | **服务类**（4 个子型） | 见下表 | 不进检索，必要时给低风险提示 |
| 6 | **数据宣称** | 含 %、倍、增长、占比、亿元、万人等 | 同宣传类 |
| 7 | **时事** | 含"今天/昨日/刚刚/最新/截至/目前" | 走通用判定 |
| 8 | **传言**（兜底） | 其余全部 | 走通用判定 |

### 2.1 服务类文案为什么单独拆出来（2026-10-23 修）

早期版本把「我帮你把 AI 真正落到业务里」判成**宣传宣称**，送进检索，检索自然查不到，于是判「尚无可举证材料 · 高风险」——**正常的小店/个人服务文案一贴就是 D 级**。这不是严格，是误伤：这类句子说的是"我提供什么服务"，公开渠道本来就不该有第三方证据。

现在拆成四个子型，都不占检索预算：

| 子型 | 例子 | 处理 | 依据 |
|---|---|---|---|
| **service**（服务说明） | 我帮你落地、教你的员工、只服务中小企业、专注中小企业AI落地、欢迎中午来吃 | 不判风险，不说它"查不到" | 服务范围描述，不是事实断言 |
| **hook**（痛点钩子） | 员工不会用、工具买了闲置？ | 不计风险 | 是提问/描述困境，不是断言 |
| **self_claim**（经营自述） | 我们开了八年、汤底熬六小时、人均25元 | **low** 提示「留存材料」 | 广告主举证责任靠自留材料，不必事前公开 |
| **service_guarantee**（效果保证） | 保证学会、无效退款 | **mid** 提示改写，**0 检索** | 《广告法》禁止对培训效果作保证性承诺 |

反过来也要守住：`_SERVICE_VERBS` 只收第一人称服务短语（帮你／为您／我能提供／教你…），**不收**"提供/开发/培训"这类通用词——否则「某公司提供虚假检测报告」会被误判成服务说明而漏查。

**另有一个正交维度：企业信用类**（`is_enterprise_credit`）
= 含"失信/被执行人/经营异常/吊销/行政处罚"等词 **且** 含"公司/企业/集团/分公司/银行"等组织词。
它不占上面 8 个位置，而是在判定阶段单独走一套口径。

## 3. 第二层：怎么检索（三轮 / 最多 9 次）

`MAX_ROUNDS = 3`，`MAX_SEARCH_PER_INVESTIGATION = 9`。

### 第一轮 · 广泛取证

| 类型 | 查询 |
|---|---|
| 传言 | ①原句 ②原句+"辟谣 真相" ③原句（限政府源） ④原句（限 news.qq.com） |
| 宣传/数据 | ①原句+"市场监管 处罚 虚假宣传" ②③④同上 |
| 企业信用 | ①主体+"失信被执行人" ②主体+"行政处罚" ③主体+"经营异常 信用中国" |
| 实时信息 | ①原句（限 1 天内） ②原句+"最新"（限 3 天内） |

### 第二轮 · 交叉验证

只有传言/宣传/数据/时事会跑；企业信用与实时信息**不跑**（名单只有政府有，实时不判真假）。

- 若第一轮已出现立场冲突：查"研究 数据 结论" + 查"不实 谣言 官方回应"（限政府源）
- 若无冲突：查"研究 论文 数据" + 查"官方 通报 标准"（限政府源）
- 若某条子主张一点证据都没有：额外补一路专门查它

### 第三轮 · 溯源一手材料

- **机构性质类**（是国企/央企/上市公司/事业单位…）：查"主体 央企名录 国资委"——它没有"传言源头"，答案在登记机关
- 其他说法：查"最早 出处 传言 起源"（限 5 年内）；有冲突再加一路政府原文

> **不提前收手**：即使第一轮就看起来一致，也照常跑完二、三轮。这是为了保证"有争议的说法拿到足够证据"。

## 4. 第三层：证据怎么洗（十道闸）

证据捞回来不能直接数条数。每条都要过十道闸，全部用规则做——**判定权不交给模型**：

| # | 闸门 | 规则 | 为什么 |
|---|---|---|---|
| 1 | 立场标注 | 先规则词表，再让模型覆盖（取前 12 条） | 词表覆盖常见表述，模型补长尾 |
| 2 | 否定式守卫 | 证据里出现「不会增加…风险」「不致癌」「没有证据表明」等否定式 → 只能算反驳（连繁体一起折成简体判断） | 模型曾把《澳專家:喝咖啡不會增加患癌風險》标成**支持**，导致整条判真 |
| 3 | 因果降级 | 断言含"致癌/导致/引起"，但证据只提前提不提后果 → 中性 | "亚硝酸盐升高"≠"会致癌" |
| 4 | 转述降级 | 支持类证据标题含"称/表示/据悉/网传/报道/专家/研究/消息" → 中性 | "媒体说有研究说X"不等于"X成立" |
| 5 | 同站矛盾清零 | 同一站点既支持又反驳 → 双方都作废 | 说明我们判错了，宁可不算 |
| 6 | 同站去重 | 同立场、同一站点多条 → 只留权重最高的一条 | 一家媒体发两条稿不是两条独立佐证 |
| 7 | 转载合并 | 同立场下标题重复（去掉标点与转载前缀后同一篇）→ 只留权重最高的一条 | 五家转载同一篇稿子不是五条独立佐证，是**一条** |
| 8 | 疑问句降级 | **只有标题以问号收尾**才降级（"隔夜菜真的会致癌吗?"）；问号在中间、后半句已给答案的不降（"国产筋骨贴冒充日本货?罚款20万!"） | 设问句不是主张；但把带答案的标题降级，会把处罚报道误杀（2026-10-23 实测事故） |
| 9 | 辟谣标记 | 站点名含「辟谣/较真」，或标题含「辟谣/谣言/不实/真相是/别再信/误区/夸大/并非」→ 直接算反驳 | 辟谣平台的稿子只会否定某说法，不该被模型判成支持 |
| 10 | 主体校验 | 反驳类证据的标题必须点到断言主体 → 否则中性 | "蛋白质吃多了不好"不能否定"鸡蛋含蛋白质" |

十道闸之后还有**最后一关** `demote_irrelevant`（三项相关性排查，见下），因此「一条证据能不能进判定」总共过 **13 项检查**。

两条补充规则（2026-10-23 因郑州广告案实测事故新增）：
- **官方处罚通报提权**：标题/摘要含"市场监管局/市场监管总局/行政处罚/处罚决定/违法广告案/查处"的，权威度不足 4 的一律提到 4——门户转载的监管通报，内容仍是一手定性。
- **宣传类的相关性放宽**：标题+摘要合并匹配，门槛降到 2 个二字片；带处罚/查处字样时命中 1 个即算——处罚稿标题常是"XX公司违法广告案"，广告原文只在摘要里。

主体校验的判定：先剥掉时间副词和动词抽出主体名词（`每天喝咖啡会致癌` → 咖啡；`鸡蛋含有蛋白质` → 鸡蛋），标题含该主体、或含 `core` 前 2 字、或含同义词（隔夜菜↔剩菜/剩饭，微波炉↔微波，咖啡↔咖啡因）才算命中。

> 闸 2、8、9、10 是同一类事故的四次修补：**模型和词表都容易被中文的设问句、否定句、繁体字带偏**。凡是「字面上出现致癌/风险」就判支持，都会把辟谣稿当成证据——所以这几道闸全部用规则做，不交给模型。
>
> 闸 6、7 解决的是另一类虚高：**同一条事实被反复收录，会凭空造出「多方印证」**。而闸 10 对应业内通行的「按文档评级，不按域名评级」——同一个政府站点的不同文章，对本条说法的证明力不同，所以权威度之外还有 `on_topic` 与强相关判断。
>
> 另外保留 bullshit-detector 的 **steelman 原则**：判「误导/假」之前，先看这句话有没有一个站得住的宽容解读——所以误导档识别不出归因纠正信号时，宁可退回「假」，也不硬扣一顶更重的帽子。

### 最后一关：`demote_irrelevant`

三件事同时做，不满足就置 `on_topic=False` 并清成中性：

1. **企业信用类**：非政府/司法来源，一律不采信
2. **主体冲突**：`subject_conflicts()` 判定是另一家法人
   - 括号注记不同：亚信科技（中国） ≠ 亚信科技（成都）
   - 核心名前多地域词：大连亚信科技 ≠ 亚信科技
   - 同集团不同分公司：中国移动…北京 ≠ 中国移动…广东
3. **主题不符**：`_strong_relevant()` 不过（标题没在讲这件事）

## 5. 第四层：怎么判（四种口径，互不混用）

`decide()` 按这个顺序走，命中即返回：

### 5.1 企业/个人信用 → `_decide_credit`

**只认政府与司法公示里的"名单本身"**

- 正面信号：正文含"失信被执行人/失信名单/被列入失信/限制高消费/被执行人名单"
- 否定信号：正文含"未列入/未被列入/无失信记录/不在失信/查无/未查询到"
- 有正面 → **真（80）**；有否定 → **假（75）**；两者都有 → **说不准（50）**
- 有政府页面但没有名单本身（处罚通报、人事处理、政策解读）→ **没查到（15）**
- 连政府页面都没有 → **没查到（10）**，并给出三个查询入口

> 处罚 ≠ 失信。高管被开除党籍 ≠ 公司不是失信企业。这两件事在代码里是隔离的。

### 5.2 实时信息

**不判真假**（40 分），只列最新来源。理由：本工具核实"说法有没有依据"，不查实时数据。

### 5.3 宣传/数据宣称 → `_decide_ad`

**举证责任倒置**：广告主对内容真实性负责，拿不出依据就不建议这么写。

- ≥2 条来源显示同类表述已被查处/认定不实 → **假（70）**，高风险
- ≥2 条官方/一手材料能支撑 → **真（65）**
- 其余 → **没查到（20）**，高风险，并列出该补哪类材料（检测报告/备案/第三方测评）

### 5.4 其他说法 → `_verdict_by_authority`

**权威优先，不数条数。**

设 `top_s` = 支持方最高权威度，`top_r` = 反对方最高权威度（只算 `on_topic` 且强相关的）：

| 情形 | 结论 | 置信度 |
|---|---|---|
| `top_s > top_r` 且 `top_s ≥ 4` | **真** | `min(90, 55 + top_s×7)` |
| `top_r > top_s` 且 `top_r ≥ 4`，且来源在**纠正归因** | **误导** | `min(90, 55 + top_r×7)` |
| `top_r > top_s` 且 `top_r ≥ 4`，来源直接定性 | **假** | `min(90, 55 + top_r×7)` |
| `top_s == top_r`（都 >0） | **说不准**，标"真分歧" | 50 |
| 最高权威 < 4 | 不下结论，走兜底 | — |

命中"真分歧"时，理由里会点名双方代表来源（谁认为成立、谁认为不成立）。

**误导档的识别（`_misleading_signal`）**：反对方证据的标题或摘要里出现"纠正归因"信号时判**误导**而不是**假**——

- 信号词：`并非`、`不是…而是`、`实为`、`原研究`、`针对的是`、`移出`、`夸大`、`以偏概全`、`张冠李戴`
- 直接定性词（`谣言`、`不属实`、`纯属`、`捏造`）→ 判**假**
- 两类信号都没有 → **保守退回「假」**（宁判假触发警觉，不误判真让人照发）

典型例子：`每天喝咖啡会致癌` —— 原文针对的是 65℃ 以上热饮，咖啡本身已被移出 2B 类名单。若最高权威**点名纠正归因**（"原文说的是 65℃ 以上的热饮"），判**误导**；若只是定性辟谣（如央视网《59 款咖啡被检出致癌物？真相是》只否定、不复述归因），**实测落到「假 · 83」**——这不是判错，是证据只到这一步。**误导档比假档窄，是刻意的：宁可判假触发警觉，不硬扣一顶更重的帽子。**

兜底分支（`evidence_kind` 词表 + 媒体计数）：仍有证据但更强权威缺位时，最多给"说不准"，绝不给真/假。

### 5.5 受理边界（比判定更早，0 检索）

`policy.check()` 在拆子主张**之前**判断，命中即返回 `refused`（不在受理范围），`searches = 0`、`provider = policy`：

| 类别 | 识别方式 | 处理 |
|---|---|---|
| 具体个人的私事 | 人名/称谓 + 私德·债务·健康·行踪类词（老赖、出轨、私生活、欠钱…）；「病情/诊断/工资/收入」这类词**必须带人物主语**才算（「我妈妈的病情」拦，「高血压的诊断标准」放行） | 拒答 |
| 时政话题 | 领导人、选举、军演、涉政事件、**外国政坛（总统/首相/大选/议会）** | 拒答 |

**企业不受此限**：查企业信用走的是政府与司法公示（名单本身），不算个人隐私。

### 5.6 常识短路（判定之前发生）

在检索之前，`check_common_knowledge()` 先过一道规则黑名单：

- 含具体机构（公司/集团/银行/法院/政府/国企/央企/上市公司/失信…）
- 含数字承诺（%/倍/亿元/第一/最高/唯一）
- 含时效词（今天/明天/今年/最新/截至）
- 含健康因果（致癌/治疗/治愈/副作用/超标/有毒/安全）

**任一命中就不算常识**，走检索。都不命中才让模型判，模型说"是"就 0 次检索直接给真（88 分），界面标"通用知识 · 未检索"。

企业信用类**永不**走常识短路。

## 6. 第五层：模型和算法怎么配合

| 环节 | 谁做 | 约束 |
|---|---|---|
| 拆子主张 | 模型（可关） | 规则版兜底 |
| 常识判断 | 规则黑名单 → 模型 | 黑名单优先 |
| 打立场标签 | 规则词表 → 模型覆盖 | 只影响权重，不直接产出结论 |
| **下判定** | **模型（补位）** | ①必须引用真实存在的证据编号 ②被引来源权威度 ≥4 ③至少引 2 条 ④只读 `on_topic` 的证据 |

`reconcile_verdict()` 的优先级：

- 宣传类/数据类/实时类/企业信用类 → **模型不参与**
- 算法已判"真分歧" → **模型不得推翻**
- 算法已有明确的真/假 → 不再多调一次模型
- 算法判"说不准/没查到"且不是分歧 → **让模型补位**；模型给定论就采纳，给不出就维持拒答

## 7. 第六层：输出必须自洽

四条一致性约束（都踩过坑）：

1. **"可用 N 条"= 判定实际用了几条**（`usable_count` 与 `usable_pool` 同源）
2. **判了真/假，就不再显示"缺少 XX 的依据"**（`missing` 清空）
3. **子主张矩阵与主结论同口径**：矩阵只在"可采信证据池"里计数；子主张措辞对不上证据时，按整条说法的证据池统计
4. **常识结果不许写"本次为实时检索"**（`provider == "knowledge"` 时显示"通用知识 · 未检索"）

## 8. 阈值总表

| 项目 | 值 |
|---|---|
| 权威度 | 0–5（gov.cn/court/新华社/人民网 4–5；财经媒体 3；门户 2；自媒体 1；未知 2） |
| 高质来源 | 权威度 ≥3 且 无利益相关 且 链接可达 |
| 权重 | `权威度 × 时效系数 × (0.5 if 利益相关)` |
| 时效系数 | ≤2 年 1.0；≤5 年 0.85；>5 年 0.7 |
| 强相关 | 标题含 core 前 3 字，或二字片覆盖 ≥ max(2, 25%) |
| 平均等级 | 体检：100 − 高×18 − 中×8；A≥85 / B≥70 / C≥55 / D<55 |
| 体检深查 | Top 8 句 |
| 违禁词 | 72 条（绝对化用语/功效承诺/医疗用语/虚假承诺等） |
| 检索 | 3 轮 / 最多 9 次 |
| 输入上限 | 体检 1000 字 / 核查 200 字 |
| 限流 | 每 IP 每小时 30 次 |
| 缓存 | 同题 2 小时（可 `force` 跳过） |

## 9. 两个入口的判断逻辑（分开看）

虽然共用一个 `investigate()` 引擎，但**上游怎么筛、下游怎么解读**完全不同。

### 9.1 文案体检的逻辑

> **读这一节前先记住界限**：「违禁词 → 规则判定、0 次检索」是**文案体检独有的第一层**。事实核查入口（9.2）**没有这一层**，它不判断是否违禁，只核事实真假；事实核查里允许 0 检索的只有「受理边界拒答」和「常识短路（标通用知识·未检索）」两种情况，其余结论必须有检索来源。两个入口共用的是下游 `investigate()` 引擎，不是这条规则快车道。

```
整段文案（≤1000 字）
  ↓ 按 。！？；换行 切句（违禁词库也按同一粒度匹配，避免两套切句打架）
句子列表
  ↓ 第一层：违禁词扫描（72 条，按法条分类）
违禁词命中句
  ↓ 规则判定，0 次检索，直接给法条依据 + 改法（标「规则判定 · 未检索」）
剩余句子（非违禁词）
  ↓ 第二层：逐句 classify_claim()
可核宣称（ad_claim / data / rumor / news）
  ↓ 取前 8 句（Top8）
深查：每句调用 investigate(budget=3, max_rounds=1)
  ↓ ——只跑 1 轮、最多 3 次检索
判定结果（真/假/误导/说不准/查不到）
  ↓ 按「广告主举证责任」映射成风险等级
high / mid / low
  ↓ 结果汇合（违禁词句 + 深查句 + 规则提示句 + 未核查句）
分数（100 − high×18 − mid×8）+ 评级 A/B/C/D + 逐句改法
```

**关键点一：第二层不依赖「规则先命中」。** 规则库覆盖不到的句式（「效率提升 320%」「权威机构认证」）只要被 `classify_claim` 判成可核宣称，同样进入深查——早期版本只从"规则命中"里挑，导致这类句子静默溜进"干净句"，一次都没查。

**关键点二：服务类句子根本不进深查队列。** 服务说明、痛点钩子、经营自述、效果保证四类（见 §2.1）各自走规则提示或不处理，把 8 个深查名额留给真正需要检索的宣称——同一段个人服务文案，修复前要烧 24 次检索并判 D，修复后 0 次检索、判 A。

**L1 快筛认的 9 类风险句式**（只定位，不下结论）：

| 类别 | 例子 | 等级 |
|---|---|---|
| 绝对化用语 | 最好、第一品牌、国家级、唯一 | high |
| 功效承诺 | 包治、根治、立竿见影、100%有效 | high |
| 绝对纯净 | 纯天然、零添加、0 添加 | high |
| 产地/身份 | 日本进口技术、德国原装 | high |
| 排名/销量 | 销量第一、全网最低、行业领先 | high |
| 权威背书 | 国家认证、官方指定、专家推荐 | high |
| 祖传/秘方 | 祖传、宫廷、百年传承 | mid |
| 恐吓式 | 千万别、致癌、有毒 | mid |
| 模糊数据 | 99% 有效、提升 80% | mid |

**违禁词库**（72 条，按法条分类：绝对化用语 / 功效承诺 / 医疗用语 / 虚假承诺等）是体检的**第一层判定**——命中即按法条给依据与改法，**0 次检索**，因为纯用词问题不需要查证。规则库与词库分工明确：规则库（9 类句式）负责"这句看着有风险，标记出来"，词库负责"这句踩了哪条法条"。

**风险映射（这是体检最关键的一步）**：

| 判定结果 | 风险等级 | 报告用语 |
|---|---|---|
| 假 | **high** | 与公开来源不符 |
| 误导 | **high** | 说法有影子但被安错了对象 |
| 查不到依据 | **high** | 尚无可举证材料 |
| 说不准 | mid | 依据不足 |
| 真 | low | 有依据支撑 |

> 「查不到依据 = 高风险」是体检与词库工具的分水岭：广告主对广告内容真实性负举证责任（《广告法》第四条、第二十八条），拿不出依据就不建议这么写。

**逐句改法怎么来的**：违禁词句有法条对应的固定改法；检索类句按判定给建议（`_FIX_BY_VERDICT`），保证不会只给结论不给动作，也不会给一句万金油：

| 判定 | 建议改法的口径 |
|---|---|
| 假 | 与公开来源不符：删去这句，或改为与来源一致的表述 |
| 误导 | 改为限定明确的说法（说清对象、条件、数据出处），不留夸大空间 |
| 查不到依据 | 拿不出依据就不建议这么写：删去这句，或换成可举证的表述（附检测报告、备案编号、统计数据出处） |
| 说不准 | 先补上可核验的出处；补不上就改为留有余地的表述（如「据我们统计」并注明口径） |
| 真 | 有依据支撑：建议在这句旁注明出处，既合规也更可信 |

**没排上深查的句子分四种，不混为一谈**：
- **规则判定（0 检索）**：违禁词命中句，纯用词问题（最、第一、包治），法条明文，本来不需要检索
- **规则提示（0 检索）**：效果保证、个人资质自称、经营自述——判的不是"网上能不能查到"，而是"这么写合不合规/要不要补材料"，依据在法条与自证逻辑里
- **待核查（未核查）**：含事实宣称（销量第一、日本进口、99%）但没排进 Top8，必须检索才知道真假——**没查就不给结论**，只标「未核查」
- **无风险**：既不是违禁词、也不是可核宣称、更不需要补材料的普通表述，不列入清单（早期版本把前两种混进"干净句"，属于误导性输出，已修）

**打分**：`100 − 高风险句×18 − 中等句×8`，封顶 0–100；A≥85 可发布 / B≥70 小幅修改 / C≥55 需修改 / 其余 D 不建议发布。

### 9.2 事实核查的逻辑

```
一条说法（≤200 字）
  ↓ 常识短路（规则黑名单 → 模型）
  ↓   命中常识：0 次检索，直接给真(88)，标「通用知识·未检索」
  ↓ 拆子主张（模型，规则兜底）
子主张列表
  ↓ 按类型分派检索策略
三轮检索（R1 广泛取证 → R2 交叉验证 → R3 溯源一手），最多 9 次
  ↓ 十道证据闸 + 最后一关三查（合计 13 项）
可采信证据池
  ↓ 按类型走四套判定口径
  ↓   企业信用 / 实时 / 宣传数据 / 权威优先（+ 模型补位）
真 / 假 / 误导 / 说不准 / 没查到可靠来源（+ 置信度 0–90）
  ↓
结论 + 可用来源数 + 子主张矩阵 + 冲突表 + 原始链接
```

### 9.3 两者的差异（逐项对照）

| 维度 | 文案体检 | 事实核查 |
|---|---|---|
| **输入** | 整段文案，≤1000 字 | 一条说法，≤200 字 |
| **先筛后查** | 先判违禁词（0 检索），剩余句里的事实宣称取 Top8 深查 | 不筛，整句全查 |
| **检索深度** | **1 轮，最多 3 次/句** | **3 轮，最多 9 次** |
| **为什么不同** | 8 句×3 次=24 次，再多成本不可接受；且广告宣称的答案往往是"有没有自家材料"，1 轮够 | 单条说法必须拿够证据，宁可多搜 |
| **判定口径** | 以「宣传/数据」类为主 → 举证责任倒置 | 四套口径按类型分派 |
| **结论语言** | 能不能这么写（与公开来源不符 / 说法被安错对象 / 尚无可举证材料 / 依据不足 / 有依据支撑） | 真 / 假 / 误导 / 说不准 / 没查到可靠来源 |
| **"查不到"的处理** | **判高风险**（广告主负举证责任） | **拒绝下结论**，只给查询入口 |
| **输出形态** | 分数 + A/B/C/D 评级 + 逐句改法 | 单一结论 + 置信度 + 来源链接 + 子主张拆解 |
| **违禁词** | 72 条词库，第一层判定，0 检索给法条依据 | 不涉及 |
| **子主张拆解** | 不展示（逐句查） | 展示矩阵，看哪一环断链 |
| **模型作用** | 与核查相同，但宣传类不走模型补位 | 算法给不出结论时模型可补位 |
| **限流消耗** | 每份文案最多 8×3=24 次检索（违禁词句 0 次） | 每次最多 9 次 |

**一句话总结差异**：体检回答**"这段文案敢不敢发"**，核查回答**"这句话是不是真的"**。前者按举证责任算风险，后者按证据强度算真伪。

## 10. 已知边界（写清楚，不藏）

1. **相关性的判断偏严**，宁可多判"查不到"——这是"绝不编"的代价。
2. **搜索引擎不适合核实常识**：实测"鸡蛋含有蛋白质"强制检索会搜到《蛋白质吃得越多越好是谣言》并误判为假，所以常识类不提供"改用检索"入口。
3. **宣传类仍按"≥2 条先例"计数**，未改权威优先（该类口径独立，是举证责任问题，不是真伪问题）。
4. **重复句的长文案**会拆出重复子主张，未做文本去重。
5. **企业信用类绝大多数会返回"没查到"**——因为失信名单本身很少被搜索引擎收录。这是正确行为，不是故障。
6. **不查具体个人的私事、不查时政**：入口 `policy.check()` 判定，命中即拒答，`searches=0`。企业信用不受此限（走政府与司法公示，不碰个人信息）。
7. **五档不是五选一的平均分布**：实际使用中「误导」档触发条件最窄（必须来源在纠正归因），多数张冠李戴类仍落到「假」——这是刻意的保守设计。
8. **服务类文案的识别靠词表与第一人称线索**：极短的碎片句（如从海报 OCR 出来的「02」「适合谁·解决什么」）仍可能落进「传言」被检索；整段连贯文案不受影响。识别不出时不硬判——只标未核查，不给结论。
9. **个人资质（证书、职称）不在公开检索范围内**：本工具不判其真假，只提示补证书名称与颁发机构，避免把"网上查不到"当成"作假"。
10. **检索是不确定的**：同一句话隔几分钟再查，返回的证据集可能不同（对标项目实测：同一内容跑三次，一半断言至少变过一次结论）。本工具的做法是把每次查询的时间戳、检索次数、证据原链都留在卡上，**一次结果当作一次读数，而不是最终定论**；判定链本身（同证据必得同结论）由 6 例离线回归守住。
11. **只能引到可访问的来源**：高权威站点反爬、付费墙、公众号不收录时，只能拿可得来源。这是"宁可说查不到也不拿营销号凑数"的代价——代价是"没查到"的比例偏高。
